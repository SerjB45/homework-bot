# Homework Bot
Telegram-бот, который обращается к API сервиса Практикум Домашка и узнаёт статус домашней работы

## Описание работы:
Бот раз в 10 минут опрашивает API сервис Практикум Домашка и проверять статус отправленной на ревью домашней работы.<br>
При обновлении статуса анализирует ответ API и отправляет соответствующее уведомление в Telegram.<br>
Вся работа бота логгируется, при возникновении проблем, дополнительно отправляется сообщение в Telegram с текстом ошибки.<br>

## Предварительная настройка перед запуском бота
1. Создать файл с переменными окружения .env
2. Внести в файл 
    - Токен для доступа к API Практикум Домашка(PRACTICUM_TOKEN)
    - Токен от бота телеграмм(TELEGRAM_TOKEN)
    - ID чата, в который необходимо отправлять сообщения(TELEGRAM_CHAT_ID)
3. Развернуть виртуальное окружение и устанровить необходимые пакеты из requirements.txt
